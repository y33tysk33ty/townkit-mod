# TownKit player guide

TownKit is a library mod for **Towntopia**, the village mod. On its own it changes almost nothing in your game. It's there so that **Towntopia addons** can change villages safely, and so that they keep working when Towntopia updates.

If a mod told you to install TownKit, this guide is for you.
