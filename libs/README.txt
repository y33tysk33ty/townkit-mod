Towntopia jars go here. They are not included in this repository because Towntopia is not TownKit's to share.

To build TownKit:
  towntopia-0.1.3.jar   (the version in gradle.properties: towntopia_version)
  Get it from Towntopia's official repository (https://github.com/town-topia-team/town-topia, jar/ folder)
  or its download page, and put it here with exactly this name.

To run all unit tests you also need:
  towntopia-0.1.2.jar   (read by five audit tests: CheckSiteScannerTest, SiteVerdictsTest, CheckSiteRewriterTest,
                         NavSiteScannerTest, NavSiteRewriterTest). Without it those parts are skipped and the
                         build still passes.

Jars in this folder are ignored by git.
