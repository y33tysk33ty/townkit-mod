# TownKit hook generator rules.
# Class names are relative to com.alex.test (e.g. village.NavGraph); '*' is a wildcard.
# "Class" alone excludes the whole class; "Class#regex" excludes matching methods.
# "@thread Class#regex" marks hooks that run off the main server thread (listeners must be thread-safe).
# "@carrier Class" targets a class with the carrier mixins although it gets no hooks (for the nav-site rewrite).
# "keep Class#regex" brings back a hook the 0.6.1 trim cut (private method, plain getter/setter, data-class
#   constructor, packet plumbing in network). It never overrides an exclusion here or abstract/synthetic/huge methods.
#   Example: keep village.FollowWalk#tickLine
#
# Exclusions are the hot paths measured or read in Towntopia's code: called per node, per step or per block
# inside searches and scans, hundreds of thousands of times per tick. Hooking them would cost real time.
